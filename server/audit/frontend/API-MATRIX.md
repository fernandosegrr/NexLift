# Matriz API de Fase 7

Generada por `node scripts/audit-backend.mjs` desde las rutas ejecutables. El JSON adjunto contiene campos, validadores, expresiones de respuesta, guards ordenados, consultas/escrituras Prisma, dependencias y consumidores por endpoint. Los contratos delegados se enlazan por archivo; no se infieren tipos que el runtime no garantiza. No existen rutas administrativas, PDF ni descargas de binarios en el backend recibido; el backup es JSON y los PDF se generan en cliente. HEAD y OPTIONS son implícitos.

# NexLift 🏋️

Tu app de gimnasio para registrar y trackear tu progreso.

## Features

- ✅ Importar rutinas via JSON
- ✅ Sistema de rutina activa
- ✅ Días colapsables con ejercicios
- ✅ Ghost Mode (muestra peso anterior a superar)
- ✅ RIR Selector (0-3)
- ✅ Progreso por grupo muscular
- ✅ Comparativas anuales
- ✅ PRs automáticos con 1RM estimado
- ✅ Diseño mobile-first premium

## Stack

- **Frontend**: React + Vite + Tailwind CSS
- **Backend**: Vercel Serverless Functions
- **Database**: PostgreSQL + Prisma

## Setup Local

```bash
# Frontend
cd client && npm install && npm run dev

# Backend
cd server && npm install && npm run dev
```

## Deploy a Vercel

1. Importa desde GitHub
2. Configura variable `DATABASE_URL`
3. Deploy automático ✨
